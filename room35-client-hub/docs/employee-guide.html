1. Introduction

The Room35 Client Hub is a secure file sharing system that allows our team to share documents with clients and receive files from them. This guide will walk you through all the features you need to know as an employee.

What Can You Do With Client Hub?

  • Upload files for specific clients (contracts, reports, invoices)
  • Upload global files visible to all clients (policies, forms, guides)
  • View files that clients have uploaded to us
  • Manage all files in one central location
  • Track downloads to see if clients have accessed their files

Supported File Types

Type Extensions Use For
Documents PDF, DOC, DOCX Contracts, reports, letters
Spreadsheets XLS, XLSX Financial reports, data
Images JPG, PNG Receipts, photos, scans
Tip: The maximum file size is 24MB. For larger files, consider compressing them or splitting into multiple files.

2. Accessing the Client Hub

Finding the Client Hub in WordPress

1 Log in to WordPress admin at yoursite.com/wp-admin

2 Look for "Client Hub" in the left sidebar menu

3 Click on it to expand the submenu options

Menu Options

Menu Item What It Does
Dashboard Overview of stats and recent files
All Files Complete list of all files in the system
Upload File Upload a new file for a client
Client Files View files organized by client

3. Understanding the Dashboard

The Dashboard gives you a quick overview of the Client Hub activity.

Stats Cards

At the top of the dashboard, you'll see five stat cards:

  • Total Files - All files in the system
  • Total Clients - Number of registered clients
  • Admin Uploads - Files uploaded by staff
  • Client Uploads - Files uploaded by clients
  • Global Files - Files shared with all clients

Recent Files Table

Below the stats, you'll see the 10 most recently uploaded files. This table shows:

  • File name and size
  • Which client it's assigned to (or "Global")
  • Whether it was uploaded by Admin or Client
  • Upload date
  • Quick action buttons to View or Download

4. Uploading Files for Clients

This is the most common task you'll perform. Here's how to upload a file:

1 Go to Client Hub → Upload File

2 Select your file:
Either drag and drop a file onto the upload area, or click to browse your computer.

3 Choose who to assign it to:

  • Specific Client - Select this, then choose the client from the dropdown
  • All Clients (Global) - Select this to make the file visible to everyone

4 Click the "Upload File" button

5 Wait for the upload to complete (you'll see a progress bar)

When to Use Global Files

Upload as a Global File when the document applies to all clients:

  • Company policies
  • General forms and templates
  • Service guides
  • Terms and conditions
  • FAQ documents
Important: When you upload a file for a specific client, they will automatically receive an email notification letting them know a new file is available.

5. Managing Files

Viewing All Files

Go to Client Hub → All Files to see every file in the system.

Table Columns

Column Description
File Name Click to view/download the file
Type File extension (PDF, DOC, etc.)
Size File size in KB or MB
Client Who it's assigned to, or "Global"
Uploaded By The person who uploaded it
Source "Admin" or "Client"
Date When it was uploaded
Actions View, Download, Delete buttons

Filtering Files

Use the dropdown filters at the top of the table:

  • All Clients - Filter by a specific client or show global files only
  • All Sources - Show only Admin uploads or Client uploads
  • Search - Type a filename to search

Deleting Files

1 Find the file in the list

2 Click the trash icon in the Actions column

3 Confirm the deletion when prompted

Warning: Deleted files cannot be recovered. Make sure you have a backup if needed.

Bulk Delete

To delete multiple files at once:

  1. Check the boxes next to the files you want to delete
  2. Select "Delete" from the Bulk Actions dropdown
  3. Click "Apply"

6. Viewing Client Files

The Client Files page lets you view all files for a specific client in one place.

1 Go to Client Hub → Client Files

2 Select a client from the dropdown menu

3 You'll see two sections:

  • Files Shared With Client - Documents you've sent them
  • Files Uploaded By Client - Documents they've sent you

What to Look For in Client Uploads

When clients upload files, check:

  • The file name - does it match what you requested?
  • The file type - is it in the correct format?
  • The date - is it recent or outdated?
Tip: You can use the download count to see if a client has accessed a file you shared with them. If it shows "0" downloads, they may not have viewed it yet.

7. Email Notifications

The Client Hub automatically sends email notifications to keep everyone informed.

When Clients Get Notified

Clients receive an email when:

  • You upload a file specifically for them

The email includes:

  • The file name
  • Upload date
  • A button to view their dashboard

When You Get Notified

Admin receives an email (sent to joshua@roomthirtyfive.com) when:

  • Any client uploads a file

The email includes:

  • Client name and email
  • File name and size
  • Upload date and time
  • A button to view in the admin dashboard
Tip: If you're not receiving notifications, check your spam folder or ask the administrator to verify the email settings.

9. Frequently Asked Questions

Q: A client says they can't see their file. What should I check?

A: Verify that:

  1. The file was uploaded and assigned to the correct client
  2. The client is logged in to their account
  3. They're looking in the "My Files" tab (not "My Uploads")

Q: Can clients see files assigned to other clients?

A: No. Clients can only see:

  • Files specifically assigned to them
  • Global files (available to everyone)
  • Files they uploaded themselves

Q: What happens if I upload a file to the wrong client?

A: Delete the file and upload it again to the correct client. Unfortunately, you cannot reassign files after upload.

Q: Can I edit a file after uploading?

A: No. You need to delete the old file and upload the updated version.

Q: How do I know if a client has downloaded their file?

A: Check the download count in Client Files or All Files view. Each time someone downloads a file, the count increases.

Q: What's the difference between "View" and "Download"?

A:

  • View - Opens the file in the browser (works for PDFs and images)
  • Download - Downloads the file to your computer

Q: Who can access the Client Hub admin area?

A: Only users with Administrator role can access the admin features. Clients only see the frontend dashboard.
