1. Plugin Overview

Description

Room35 Client Hub is a secure file management plugin that enables bidirectional file sharing between administrators and clients. It provides a branded client portal with modern design aesthetics.

Key Features

  • Secure file uploads and downloads
  • Client-specific and global file assignments
  • Modern frontend dashboard via shortcode
  • Email notifications for file activities
  • Custom "Client" user role
  • Protected file storage with PHP-based serving
  • Responsive black/white design with Poppins font

System Requirements

Requirement Minimum Recommended
WordPress 5.8+ 6.0+
PHP 7.4+ 8.0+
MySQL 5.7+ 8.0+
Memory Limit 64MB 128MB+

2. Installation

Standard Installation

  1. Upload the room35-client-hub folder to /wp-content/plugins/
  2. Activate the plugin through the WordPress admin "Plugins" menu
  3. The plugin will automatically create required database tables and the client dashboard page

What Happens on Activation

When activated, the plugin:

  • Creates two database tables (wp_r35_hub_files and wp_r35_hub_download_log)
  • Creates a protected upload directory at wp-content/uploads/room35-client-files/
  • Adds .htaccess to block direct file access
  • Creates the "Client" user role
  • Creates a "Client Dashboard" page with the shortcode
  • Sets default plugin options

Uninstallation

The plugin supports clean uninstallation. To remove all data:

  1. Go to Client Hub → Settings
  2. Enable "Delete data on uninstall" option
  3. Deactivate and delete the plugin
Warning: Enabling "Delete data on uninstall" will permanently remove all files and database records when the plugin is deleted.

3. Shortcodes Reference

Main Shortcode

Basic Usage

[room35_client_hub]

This shortcode displays the complete client dashboard including:

  • My Files tab (files shared with the logged-in user)
  • General Documents tab (global files)
  • Upload File tab (client file upload form)
  • My Uploads tab (files the client has uploaded)

Shortcode Attributes

Attribute Type Default Description
show_upload string "true" Show/hide the file upload form
show_global string "true" Show/hide the global files tab

Shortcode Examples

Full Dashboard (Default)

[room35_client_hub]

Shows all tabs: My Files, General Documents, Upload, My Uploads

View Only (No Upload)

[room35_client_hub show_upload="false"]

Hides the upload form - clients can only view and download files

Personal Files Only

[room35_client_hub show_global="false"]

Hides the global files tab - shows only files assigned to specific client

Minimal View

[room35_client_hub show_upload="false" show_global="false"]

Shows only personal files assigned to the client - no global files, no upload

Login Behavior

If a user is not logged in, the shortcode displays a login form instead of the dashboard. Features:

  • Username/email and password fields
  • "Remember me" checkbox
  • Forgot password link
  • Registration link (if WordPress registration is enabled)

4. User Roles & Capabilities

Client Role

The plugin creates a custom "Client" role with minimal capabilities:

Capability Value Description
read true Basic access to view content
upload_files false Cannot upload via Media Library (uses custom system)

Auto-Registration

New user registrations are automatically assigned the "Client" role, unless they already have administrator capabilities.

Note: The "Client" role is named r35_client internally to avoid conflicts with other plugins.

5. File Storage & Security

File Location

All uploaded files are stored in:

wp-content/uploads/room35-client-files/

Directory Structure

room35-client-files/
├── .htaccess          # Blocks all direct access
├── index.php          # Prevents directory listing
├── global/            # Global files
│   └── index.php
├── johndoe/           # Files for user "johndoe"
│   └── index.php
└── janesmith/         # Files for user "janesmith"
    └── index.php

Security Measures

1. Direct Access Protection

The .htaccess file denies all direct HTTP access:

# Room35 Client Hub - Deny direct access
Order deny,allow
Deny from all

<FilesMatch ".*">
    Order Allow,Deny
    Deny from all
</FilesMatch>

2. PHP-Based File Serving

Files are served through a secure PHP endpoint:

https://yoursite.com/r35-download/{file_id}-{action}/

Where action is either view or download.

3. Permission Checks

Before serving any file, the system verifies:

  • User is logged in
  • User has permission to access the file (owner, assigned client, or admin)
  • File exists and is active (not deleted)

4. Upload Validation

All uploads are validated for:

  • File size (max 24MB by default)
  • MIME type verification (actual file content, not just extension)
  • Extension matching MIME type
  • Path traversal prevention

Allowed File Types

MIME Type Extension
application/pdf .pdf
application/msword .doc
application/vnd.openxmlformats-officedocument.wordprocessingml.document .docx
application/vnd.ms-excel .xls
application/vnd.openxmlformats-officedocument.spreadsheetml.sheet .xlsx
image/jpeg .jpg, .jpeg
image/png .png

6. Database Structure

Files Table

wp_r35_hub_files

Column Type Description
id BIGINT(20) Primary key, auto-increment
file_name VARCHAR(255) Sanitized filename on disk
original_name VARCHAR(255) Original filename as uploaded
file_path VARCHAR(500) Relative path from uploads directory
file_type VARCHAR(100) MIME type
file_size BIGINT(20) Size in bytes
file_hash VARCHAR(64) SHA256 hash for integrity
uploaded_by BIGINT(20) User ID of uploader
assigned_to BIGINT(20) User ID of assigned client (NULL for global)
is_global TINYINT(1) 1 = visible to all clients
upload_source ENUM 'admin' or 'client'
status ENUM 'active' or 'deleted'
download_count INT(11) Number of downloads
created_at DATETIME Upload timestamp
updated_at DATETIME Last modified timestamp

Download Log Table

wp_r35_hub_download_log

Column Type Description
id BIGINT(20) Primary key, auto-increment
file_id BIGINT(20) Reference to files table
user_id BIGINT(20) User who downloaded
ip_address VARCHAR(45) Client IP address
user_agent VARCHAR(500) Browser user agent
downloaded_at DATETIME Download timestamp

8. Troubleshooting

Common Issues

Files not uploading

  • Check PHP upload_max_filesize in php.ini (should be ≥24M)
  • Check PHP post_max_size in php.ini (should be ≥25M)
  • Verify the uploads directory is writable
  • Check for JavaScript errors in browser console

Direct file URLs not working

  • Ensure mod_rewrite is enabled (Apache)
  • Flush permalinks: Settings → Permalinks → Save
  • For NGINX, add rewrite rules manually

Emails not sending

  • Verify WordPress can send emails (test with other plugins)
  • Check spam folder
  • Consider using an SMTP plugin for reliable delivery

Dashboard page blank

  • Check for PHP errors in debug.log
  • Verify the shortcode is correctly placed: [room35_client_hub]
  • Disable other plugins to check for conflicts

NGINX Configuration

If using NGINX, add this to your server block:

# Block direct access to client files
location ^~ /wp-content/uploads/room35-client-files/ {
    deny all;
    return 403;
}

# Rewrite for secure downloads
location /r35-download/ {
    rewrite ^/r35-download/(.*)$ /index.php?r35-download=$1 last;
}
